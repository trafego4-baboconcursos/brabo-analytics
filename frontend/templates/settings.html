O projeto (INSS/TJ-SP/Banco do Brasil) é detectado pelo prefixo do código (PI/PES/PBB). As datas de início/fim aqui são só um período aproximado — o calendário e o resto do sistema usam as datas detalhadas por etapa que você preenche no wizard, que abre em seguida.

Arquitetura de Dados Analíticos (Supabase)
Pipeline ETL (scheduler.py) ➔ Datalake Supabase
  ├── dim_lancamentos       ➔ Cadastro de lançamentos e períodos
  ├── meta_ads_daily        ➔ Desempenho diário de anúncios Meta Ads API
  ├── google_ads_daily      ➔ Desempenho diário de anúncios Google Ads API
  ├── leads                 ➔ Base consolidada de leads (Active Campaign)
  ├── typeform_respostas    ➔ Respostas das pesquisas (Typeform legado + sistema interno)
  ├── hotmart_clean_oficial ➔ Vendas integradas e normalizadas Hotmart
  └── tmb_clean_oficial     ➔ Vendas integradas e normalizadas TMB Pay
